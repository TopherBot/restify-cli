# Restify CLI

**One‑sentence summary** – A minimalist command‑line tool that nudges you to pause for a 30 second break at regular intervals, keeping you refreshed without leaving your terminal.

---

## ✨ What it does
- Runs in the background (or foreground) and prints a reminder every `N` minutes.
- Optionally sends a desktop notification on macOS, Linux, and Windows.
- Zero‑configuration defaults to a 60 minute interval and a friendly message.
- No hidden services, no GUI, just a single Python script.

---

## 📦 Installation
### From PyPI (recommended)
```bash
pip install restify-cli
```
The entry‑point creates a `restify` command you can call from anywhere.

### Or run the script directly
```bash
git clone https://github.com/your‑username/restify-cli.git
cd restify-cli
python3 restify.py --interval 45   # start with a 45‑minute timer
```

---

## 🚀 Quick start
```bash
# Take a break every hour (default)
restify

# Every 30 minutes with a custom message
restify --interval 30 --message "Stretch time!"

# Silent mode (no desktop notification, just console output)
restify --no-notify
```
The program runs until you press **Ctrl‑C**.

---

## 📖 When *not* to use Restify CLI
| Use‑case | Why Restify isn’t a good fit |
|----------|-------------------------------|
| Pomodoro timer with statistics | Restify has no tracking or work‑session logs. Use a dedicated Pomodoro app. |
| Integrated IDE reminders | IDE plugins can hook into editor events; Restify is terminal‑only. |
| Multi‑user or server‑wide scheduling | Restify is a personal, per‑process tool. |

If your needs exceed a simple interval reminder, consider a more feature‑rich solution.
